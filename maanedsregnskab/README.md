# NIRAS månedsregnskab

Side der viser NIRAS-koncernens månedsrapport »Director Specification« (Trafiklys) med fokus på DSGN og Byggeri.

- Åbn siden og træk en eller flere Trafiklys-PDF'er ind.
- PDF'erne læses i browseren med PDF.js, som er bygget ind i `index.html`. Intet sendes til GitHub eller andre steder, og intet gemmes, når fanen lukkes.
- »Gem som rapport« henter en HTML-fil med tallene indbygget til din egen computer.

Læg aldrig PDF'er, gemte rapporter eller andre filer med tal i dette repo. Det er offentligt.
